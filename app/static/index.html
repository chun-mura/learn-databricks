プラットフォーム基盤

Azure Databricks
Microsoft Azure 上で動く統合データ・AI プラットフォーム。ノートブック・ジョブ・SQL・ML が一体化している。
公式ドキュメント →
ADLS Gen2 Azure Data Lake Storage Gen2
Azure の大規模ストレージ。Databricks のデータ保存先として使う。階層型名前空間が特徴。
公式ドキュメント →
Unity Catalog
Databricks のデータガバナンス基盤。カタログ／スキーマ／テーブル／Volume の権限を一元管理する。
公式ドキュメント →
🔄

データ層・パイプライン

Delta Lake
ACID トランザクション対応のオープンフォーマット。Databricks のデフォルトストレージ形式で Lakehouse を実現する。
公式ドキュメント →
Medallion アーキテクチャ Bronze / Silver / Gold
データ品質を段階的に高めるレイヤ設計。Bronze=生データ、Silver=正規化、Gold=業務集計。
公式ドキュメント →
Unity Catalog Volumes
ファイル（PDF・画像など）を UC で管理する非テーブルストレージ。Bronze 層への PDF 格納に使う。
公式ドキュメント →
Auto Loader
クラウドストレージへの新着ファイルを自動検知してインクリメンタル取込するストリーミング取込機能。
公式ドキュメント →
Lakeflow Jobs 旧 Workflows
バッチ・定期実行・パイプライン管理。Silver/Gold 変換ジョブや通知に使う。
公式ドキュメント →
ai_parse_document 関数
SQL 関数。PDF や画像を LLM でパースして構造化データに変換する。許認可書類の抽出に使う。
公式ドキュメント →
🤖

AI・エージェント

Mosaic AI Agent Framework
Databricks 公式のエージェント開発フレームワーク。ツール呼び出し・RAG・MLflow 統合が揃っている。
公式ドキュメント →
Unity AI GatewayBeta
エージェントからの LLM 呼び出しを一元管理するプロキシ。権限・レート制限・ガードレール・推論ログを提供。
公式ドキュメント →
Foundation Model APIs
Databricks が提供する LLM エンドポイント（Azure OpenAI 等）。AI Gateway 経由で呼び出す。
公式ドキュメント →
Model Serving
カスタムモデル（埋め込みモデル等）をリアルタイム API として提供する推論基盤。図面埋め込みモデルのホストに使う。
公式ドキュメント →
LangGraph / LangChain
Python 製エージェントオーケストレーションライブラリ。状態管理・ツール呼び出し・マルチエージェントに対応。
公式ドキュメント →
マルチエージェント Supervisor パターン
複数エージェントを Supervisor が統括するパターン。本プロジェクトの 2 エージェント統合に対応。
公式ドキュメント →
🔍

検索・ナレッジ

Vector Search
Delta テーブルと同期するベクトル検索エンジン。テキスト・図面の類似検索インデックスを作る。
公式ドキュメント →
RAG Retrieval-Augmented Generation
検索して得たドキュメントを LLM のコンテキストに付与して回答精度を上げる手法。Vector Search と組み合わせる。
公式ドキュメント →
BYO Embeddings 自前埋め込みモデル
Vector Search で外部モデルの埋め込みを使う方法。図面（マルチモーダル）検索に必要。
公式ドキュメント →
🚀

UI・デプロイ・運用

Databricks Apps
Databricks 上で Python Web アプリをホストする機能。Chat UI 埋め込みや業務画面に使う。OAuth・UC 統合済み。
公式ドキュメント →
MLflow
実験管理・モデルレジストリ・トレース・評価を提供する OSS。エージェントの回答品質追跡に使う。
公式ドキュメント →
Databricks Asset Bundles
YAML で Databricks リソース（Jobs・Apps・エンドポイント）を IaC 管理する CI/CD ツール。
公式ドキュメント →
Lakeview ダッシュボード
Databricks SQL の結果をノーコードで可視化するダッシュボード機能。本開発の進捗・利用量表示に使う。
公式ドキュメント →
システムテーブル
Databricks が自動収集する利用量・監査・コストのメタデータテーブル。ガバナンス可視化に使う。
公式ドキュメント →
